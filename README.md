# Kocaeli Üniversitesi Bilgisayar Kulübü (KOUBK)

KOUBK topluluğunun stant haftalarında, sosyal medyada (Instagram bio) ve etkinliklerde kullandığı resmi bağlantı ve tanıtım sayfası.

## Özellikler

- **Linktree & Hub**: Üye başvuru formu, Discord, Instagram, LinkedIn, X ve GitHub bağlantıları tek ekranda.
- **Tasarım Dili**: Kulübün afiş ve stant materyallerine uygun KOU kurumsal kırmızı tonları, Liquid Glass (cam morfolojisi) ve responsive mobil öncelikli arayüz.
- **Karanlık / Aydınlık Mod**: Sistem tercihini otomatik algılar veya manuel değiştirilebilir.
- **Stant İçin Hızlı QR**: Kamerayla okutarak anında sayfaya erişim sağlayan modal.
- **Sıfır Bağımlılık**: Saf HTML, CSS ve JS. Node veya derleme adımı gerektirmez.

## Yerel Çalıştırma

Projeyi tarayıcıda doğrudan açabilirsiniz:

```bash
cd koubk
python3 -m http.server 8000
```

Ardından tarayıcınızdan `http://localhost:8000` adresine gidin.
