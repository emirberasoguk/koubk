# Kocaeli Üniversitesi Bilgisayar Kulübü (KOUBK)

KOUBK topluluğunun stant haftalarında ve etkinliklerde kullandığı resmi bağlantı ve tanıtım sayfası.

Tasarım dili [emirberasoguk.github.io](https://emirberasoguk.github.io) referans alınarak **Bauhaus / Neo-Brutalist** estetiğinde geliştirilmiştir.

## Özellikler

- **Bauhaus Estetiği**: Tactile Hard Shadows, kalın siyah konturlar, geometrik soyut öğeler ve KOU kırmızısı vurguları.
- **💥 Destroy This Site**: 2D fizik motoru ve yerçekimi simülasyonu ile sayfadaki öğelerin yıkıldığı ve tek tıkla yeniden inşa edildiği eğlenceli interaktif modül.
- **Resmi Bağlantılar**: KOUBK Üyelik Başvuru Formu, Instagram, LinkedIn, X ve Kocaeli Üniversitesi resmi portalları.
- **Stant İçin Hızlı QR**: Kamerayla okutarak anında sayfaya erişim sağlayan modal.
- **Sıfır Bağımlılık**: Saf HTML, CSS ve Vanilla JS. Derleme veya framework bağımlılığı yoktur.
